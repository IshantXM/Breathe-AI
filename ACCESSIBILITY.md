# Accessibility

Verified in automated tests: semantic shell landmarks, SVG text alternatives, and focus entry, wrap, and restoration for the About dialog. The app also includes a skip link, keyboard navigation, named controls, an accessible mobile drawer, and reduced motion via both app preference and the operating system setting. Not all content is translated.

Before presenting, tab through the dashboard and desktop sidebar, open and dismiss the mobile drawer at 375 px, confirm the skip link moves focus to main, check both themes and high contrast, and try the heatmap, routine status, and dialog with NVDA or VoiceOver. Check zoom/reflow and contrast in a real browser. These features and DOM tests do not establish WCAG 2.2 AA conformance.
